将网站免费发布上线供多人观看

只需 1 分钟即可将本页面部署到网络，全场观众扫码即可观看！

方案 1：使用 Netlify Drop (最简单/零代码)

  1. 在 VS Code 中把这份代码保存为文件名 index.html。
  2. 打开网址 app.netlify.com/drop。
  3. 将包含 `index.html` 的文件夹拖拽上传到页面中。
  4. Netlify 会立即生成一个网址（如：`big-eater.netlify.app`），分享给观众即可！

方案 2：使用 GitHub Pages / Vercel

  1. 在 GitHub 新建仓库（Repository）并将代码 Push 提交。
  2. 在仓库的 Settings -> Pages 中将 Source 设置为 `main` 分支。
  3. 发布后即可获得免费的 HTTPS 官方访问网址。
✨ 操作成功！
